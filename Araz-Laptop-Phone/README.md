# Araz Laptop Phone 📞

نسخهٔ آمادهٔ رابط تلفن برای لپ‌تاپ، بدون نیاز به سیم‌کارت.

## فایل‌ها
- `index.html` — شماره‌گیر و رابط تلفن آماده برای استفادهٔ نمایشی
- `setup.html` — دستیار تنظیمات برای آماده‌سازی اتصال VoIP

## نکته
نسخهٔ فعلی عمداً تماس واقعی برقرار نمی‌کند. برای تماس واقعی با شماره‌های عادی، باید سرویس VoIP/Voice و یک شمارهٔ فعال از یک ارائه‌دهنده تهیه و به نسخهٔ نرم‌افزاری متصل شود.
